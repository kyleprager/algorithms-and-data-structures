algorithms-and-data-structures
==============================

My own implementations of some algorithms and data structures in Java. This is meant to help myself and others understand and practice the fundamentals of computer science, as well as show some examples of how they are utilized to solve coding questions in an interview. 

Here is a quick breakdown of the code in the src/org/kprager folder:

**/questions:** This folder puts it all together, utilizing the data structures and algorithms to solve coding questions you might see on an interview.
Questions.java - uses the algorthms and datastructures to solve a few coding questions. They include:
- Find the two largest numbers in a binary search tree (BST).
- Given a pre-order and in-order traversal of a BST, recreate the tree.
- Given 2 nodes in a BST, find their closest common parent.
WordSplit.java - Given a string, ex: "peanutbutter", split it into all possible lists of subwords. EX: yes: "peanut butter", no: "pea nut butt er" - "er" is not a word.
Dictionary.java - uses the "enable1.txt" list of dictionary words to create a Trie data structure for fast lookup via an in-memory dictionary.
